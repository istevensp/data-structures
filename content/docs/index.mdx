Este sitio reúne los materiales de **CCPG1034 Estructuras de Datos** y los organiza según el parcial y el tópico al que pertenecen.

## Cómo recorrer el contenido

1. Elige el parcial que estás cursando.
2. Abre el tópico desde la navegación lateral.
3. Dentro de cada tópico encontrarás, según disponibilidad, diapositivas, guías, ejercicios, código Java y archivos descargables.

- [Primer Parcial](./1p/): fundamentos y herramientas que preparan el trabajo con estructuras de datos.
- [Segundo Parcial](./2p/): materiales de Árboles y Grafos.

## Cómo está distribuido

Cada página de tópico tiene un catálogo YAML asociado. Ese catálogo mantiene el nombre original, tipo, tamaño, metadatos y ruta del material. Los archivos Java se almacenan como código fuente; los PDF, PPT/PPTX, ZIP y TXT se presentan como descargas.

## Para estudiantes que clonan el repositorio

La estructura académica está separada de la infraestructura del sitio: las páginas viven en `src/content/docs`, los catálogos en `src/content/materials`, el código en `src/assets/code` y las descargas en `public/files`. El `README.md` del repositorio explica cómo instalarlo y ejecutarlo localmente.
